## 2. 复刻步骤（均已执行并通过冷启动验证）

### 2.1 部署代码
- 从本仓库 main 分支取代码 → Pi 的 `~/imu_ws`（`src/`、`web_server/`、`pc_host/`）。
- 全量替换 `hansing → han`。
- `camera_stream.py` 放 `/home/han/camera_stream.py`。

### 2.2 系统依赖（apt 源换清华 TUNA 镜像：ubuntu-ports + ros2）
```bash
# ROS2 key + 源
wget -qO- https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  | sudo gpg --dearmor -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=arm64 signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
  https://mirrors.tuna.tsinghua.edu.cn/ros2/ubuntu noble main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list
sudo apt update
sudo apt install -y --no-install-recommends \
  ros-jazzy-ros-base ros-jazzy-rclc ros-jazzy-sensor-msgs \
  ros-jazzy-std-msgs ros-jazzy-std-srvs \
  python3-colcon-common-extensions python3-rosdep \
  build-essential cmake git python3-spidev ffmpeg v4l-utils curl
# 设备访问权限：spidev/ttyUSB 属 dialout，摄像头属 video
sudo usermod -aG dialout,video han
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
```

### 2.3 编译 ROS2 IMU 驱动
```bash
cd ~/imu_ws
source /opt/ros/jazzy/setup.bash
colcon build --packages-select imu_serial_driver
```

### 2.4 启用硬件接口 `/boot/firmware/config.txt`
镜像已带 `dtparam=spi=on`、`dtparam=i2c_arm=on`、`camera_auto_detect=1`；补充：
```
enable_uart=1
dtoverlay=disable-bt
dtoverlay=pwm-2chan
```

### 2.5 网线直连固定 IP
```bash
sudo bash ~/imu_ws/web_server/setup_eth_direct.sh   # eth0 = 192.168.50.1/24
sudo chmod 600 /etc/netplan/*.yaml                  # 消除权限告警
```

### 2.6 开机自启（用户级 systemd 服务，免登录）
```bash
loginctl enable-linger han                          # 需 sudo
export XDG_RUNTIME_DIR=/run/user/$(id -u)
bash ~/imu_ws/web_server/install_propeller_service.sh
```
守护脚本 `start_propeller_daemon.sh` 逻辑：依次等 eth0(192.168.50.1) → spidev0.0 →
ttyUSB0(最多 45s) → 拉起 IMU 驱动(检测到才起) + 网页服务(8080)；摄像头不自启，
由网页「启动摄像头」按钮手动拉起(8081)。

## 3. 缺失文件说明：`camera_stream.py`

本仓库 **未包含** `camera_stream.py`（原文件在已损坏的 Pi5 rootfs，从未提交）。
已按功能重建一份等价实现：ffmpeg 抓取 `/dev/video0`，在 **8081 端口 `/stream`** 输出
`multipart/x-mixed-replace` MJPEG，默认 1920×1080，失败自动逐级降级；网页
`index.html` 通过 `<img src="http://<pi>:8081/stream">` 拉流。**如找到原版可直接替换。**
